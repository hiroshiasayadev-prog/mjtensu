## Goal

Create the deterministic versioned semantic scoring corpus required to verify the Agari fork and TypeScript adapter against the complete accepted product scoring surface.

## Work

- Define a reviewable fixture schema using product tile/condition/rule/result semantics rather than Agari display strings.
- Add positive ordinary, chiitoitsu, kokushi, yaku, dora/aka, fu, limit, yakuman, and payment cases required by the testing strategy.
- Add rule-switch pairs for kiriage, counted yakuman, double-yakuman variants, multiple yakuman, double-wind pair fu, open tanyao, aka dora, indicator dora, and ippatsu.
- Add negative/not-ready cases distinguishing non-winning shape, no-yaku, and dora-only bonus.
- Record expected yaku IDs/han, dora counts, FuCalculation semantics, LimitClassification, and payment values explicitly.
- Add fixture schema validation/helpers needed for later S06 execution without embedding a second scoring engine.
